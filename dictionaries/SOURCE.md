# Spelling dictionaries

Hunspell dictionaries for the spell checker, unchanged from the LibreOffice dictionaries repository
(https://github.com/LibreOffice/dictionaries, folder `en`, commit `e7f163feb2beaf526135132d8716e68e19d2716e`).

| Files | Language | License (see the README) |
|-------|----------|--------------------------|
| `en_US.dic`, `en_US.aff` | English (United States) | SCOWL: BSD-style permissive license, public domain parts (`README_en_US.txt`) |
| `en_GB.dic`, `en_GB.aff` | English (United Kingdom) | GNU LGPL (`README_en_GB.txt`, `LGPL-3.0.txt`) |

The files are kept byte for byte (`.gitattributes`: `-text`). More languages can be added by putting a
`<code>.dic` / `<code>.aff` pair here (shipped with the app) or into the user's dictionary folder (see README).
